ШКОЛЬНЫЙ ЗАБЕГ — обучающая игра по математике от таблицы умножения до ЕГЭ и вуза
==================================================================================

Что это
-------
Герой бегает по школе (холл + 7 этажей + университет), заходит в кабинеты-уроки, решает задачи на время,
собирает шпаргалки с формулами, побеждает боссов-экзаменаторов, обгоняет соперника Гошу Зубрилкина,
сдаёт «настоящий» ЕГЭ (20 задач на время) и поступает в Университет Великих Умов.
Одна страница: index.html + скрипты. Работает в браузере, как PWA и как APK (WebView-обёртка в android/).

Запуск
------
  Браузер:   открыть index.html (лучше через любой локальный сервер, например: python tools/devserver.py)
  На телефоне: собрать APK (android/build_apk.bat) и поставить файл из Desktop\android games apk.

Сюжет и этажи
-------------
  Первый этаж   — Начальная школа (сложение, таблица умножения, деление, порядок действий, единицы)  босс: Дракон Таблица
  Второй этаж   — 5–6 класс (уравнения, дроби, десятичные, проценты, степени, НОД/НОК, пропорции)       босс: Король Дробей
  Третий этаж   — 7 класс (линейные уравнения, ФСУ, выражения, линейная функция, графики, системы)       босс: Икс-Хамелеон
  Четвёртый     — 8 класс (площади, углы, Пифагор, окружность, подобие, координаты, квадратные уравнения) босс: Сфинкс Гипотенузы
  Пятый         — 9 класс / ОГЭ (парабола, гипербола, прогрессии, неравенства, вероятность, статистика)  босс: Гидра ОГЭ
  Шестой        — 10 класс (степени, логарифмы, тригонометрия, показательные и сложные уравнения)       босс: Кракен Логарифмов
  Седьмой       — 11 класс / ЕГЭ (производная, графики производной, стереометрия, проценты и кредиты,
                  движение и работа, практические задачи, «верные утверждения»)                         босс: Ужас ЕГЭ (пробник)
  Кабинет директора — ЕГЭ: 20 задач на время, без подсказок, итог — баллы из 100 (для вуза нужно 50+)
  Университет   — пределы, производные, интегралы, матрицы, комплексные числа, векторы                  босс: Декан Матана

Всего 65 тем, около 200 типов задач, ~100 карточек-формул с примерами.

Как игра мешает «сфотографировать и спросить нейросеть»
-------------------------------------------------------
  1. Каждая задача создаётся случайно (генераторы в content*.js): у каждого игрока и каждого запуска свои числа.
  2. У задачи есть таймер. Ответил за половину времени — бонус «молния» ×1,5 и рост освоения темы.
  3. Время вышло ИЛИ игру свернули больше чем на 2,5 с — вариант меняется на новый (старое фото бесполезно),
     а за ответ на «штрафной» вариант нет ни монет, ни освоения темы, ни звёзд (только допуск к уроку).
  4. Освоение тем (0–100%) растёт только от быстрых/своевременных правильных ответов, падает от ошибок и со временем
     (кривая забывания). «Прогноз ЕГЭ» считается по освоению — переписанные ответы его не поднимут.
  5. ЕГЭ и босс-экзамены идут с ужатым временем, без подсказок.
  Честно: полностью исключить обман на устройстве нельзя, но игра делает его невыгодным и медленным.

Система наград
--------------
  🪙 монеты (+ скорость, + комбо, + питомец), ✨ опыт → ранги (Первоклашка … Академик), ⭐ звёзды за уроки,
  🃏 шпаргалки (за первое прохождение, боссов и светящиеся шкафчики), 🎁 подарки за вход (7-дневный цикл),
  📋 три задания дня + сундук, 🏆 35+ достижений, 🥇 рейтинг класса (одноклассники растут каждый день),
  🛍 столовая (подсказка, 50/50, +время, замена задачи, справка = +1 жизнь, двойной компот),
  👕 гардероб (причёски, цвета, одежда, рюкзаки, шапки, очки, шлейфы, питомцы с бонусами),
  🏃 «Коридорный забег» и 🥇 «Олимпиада» (бесконечный режим) в спортзале, ⚔️ дуэль с Гошей раз в день.

Структура файлов
----------------
  index.html     — разметка, стили (всё интерфейсное рисуется скриптами)
  content.js … content4.js — генераторы задач (core + главы 0–7), проверка ответов
  formulas.js    — карточки формул
  data.js        — главы, сюжет, диалоги, магазин, достижения, задания
  state.js       — сохранение (localStorage), опыт, освоение, прогноз ЕГЭ, достижения
  figures.js     — рисунки к задачам (фигуры, графики, тела, диаграммы)
  world.js       — карты школы, герой, прохожие, рендер, управление
  ui.js          — диалоги, меню, магазин, гардероб, библиотека, рейтинг, настройки
  lesson.js      — движок уроков, боссов, ЕГЭ, олимпиады
  runner.js      — мини-игра «Коридорный забег»
  game.js        — запуск
  sw.js, manifest.webmanifest, icons/ — PWA
  android/       — APK-обёртка (build_apk.bat → school-<версия>.apk и копия в Desktop\android games apk)
  tools/         — test_gen.js (проверка генераторов: node tools/test_gen.js), sample.js (примеры задач),
                   figs.html (галерея рисунков), make_icons.js (иконки), devserver.py (локальный сервер без кэша)

Как добавить задачи
-------------------
  В content*.js: def('id', { name, ch, icon, learn, formulas:[id карточек], gens:[g(минимальная_сложность, d => N(...)|F(...)|C(...)), ...] }).
  N — числовой ответ, F — дробь, C — выбор из вариантов (можно с рисунками {fig:{...}}).
  После правок: node tools/test_gen.js — проверит все генераторы (ответ самосогласован, варианты уникальны и т. д.).

Версии и обновление APK
-----------------------
  Версия берётся из const VERSION в state.js. Поднимите её и запустите android/build_apk.bat — APK встанет поверх старого
  (ключ school-release.keystore в android/ не удаляйте: без него обновление поверх не поставится).
  Прогресс хранится на устройстве (localStorage). Перенос между устройствами — «Настройки → Перенос прогресса».
